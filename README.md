A one-star review of Monday, written as if Monday were a restaurant —
for the make.fun competition "One Star for Monday".

Bounty page: https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61

## The line

> One star. The host seated me next to my inbox, the special was overtime, and the bill came before the coffee.

## How it works

`main.py` (pure Python standard library) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The output is byte-identical on repeat runs.
